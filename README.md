# 跨夜班次考勤核算工具

仅使用 Go 标准库实现的本地考勤核算工具。将排班、上下班打卡和已批准请假整理成可追溯的出勤报告，明确区分缺卡、迟到、早退与缺勤时间。

## 运行方式

```sh
go run ./cmd/attendance -dir ./data
```

程序从标准输入逐行读取 JSON 请求，每处理一行就向标准输出写一行 JSON 响应。`-dir` 指定本地数据目录，数据保存在该目录下的 `data.json`（原子写入），进程重启后结果一致。

## 时间与区间约定

- 所有时间统一为北京时间（UTC+8），格式 `YYYY-MM-DD HH:mm`；日期筛选格式 `YYYY-MM-DD`。
- 所有时间区间均为左闭右开 `[start, end)`，首尾相接不算重叠。
- 班次可跨越午夜，但起止不得相同；报告按班次开始日期归属，跨夜班次不拆分成两次出勤。
- 报告的日期筛选含起止两端（按班次开始日期判断）。

## 命令

### 登记员工

```json
{"cmd":"add_employee","id":"E1","name":"张三"}
```

### 批量导入排班

```json
{"cmd":"import_shifts","shifts":[
  {"id":"S1","employee_id":"E1","start":"2026-09-01 22:00","end":"2026-09-02 06:00",
   "breaks":[{"start":"2026-09-02 02:00","end":"2026-09-02 02:30"}]}
]}
```

- `breaks` 可选，休息区间必须落在班次内，重叠休息先取并集，不计入应出勤分钟。
- 同一员工的班次不得重叠。

### 批量导入请假

```json
{"cmd":"import_leaves","leaves":[
  {"id":"L1","employee_id":"E1","start":"2026-09-01 22:00","end":"2026-09-02 01:00"}
]}
```

请假只抵扣与班次工作区间（班次减去休息）重叠的部分；多张请假重叠时只抵扣一次。整班请假或应出勤为零的班次仍会列出，不会出现负时长。

### 批量导入打卡

```json
{"cmd":"import_punches","punches":[
  {"id":"P1","employee_id":"E1","shift_id":"S1","type":"in","time":"2026-09-01 22:10"},
  {"id":"P2","employee_id":"E1","shift_id":"S1","type":"out","time":"2026-09-02 06:00"}
]}
```

- `type` 为 `in`（进入）或 `out`（离开），打卡员工必须与班次员工一致。
- 允许乱序导入，核算时按时刻再按标识排序后逐一配对；同分钟的进出配对计零分钟。
- 连续进入、连续离开、开头离开或最后缺少离开均标记缺卡：明细中列出异常记录，不猜测补卡时间，该班次不参与分钟汇总但计入异常数量。
- 完全没有打卡不算缺卡，按无在场时间处理（全部计缺勤）。

### 生成期间报告

```json
{"cmd":"report","employee":"E1","from":"2026-09-01","to":"2026-09-30"}
```

返回汇总与逐班明细。完整打卡对形成在场区间，与应出勤区间求交得到有效出勤（不计算加班，班外打卡不计入）：

- 应出勤区间中早于首次有效出勤的部分计 `late_minutes`（迟到）；
- 晚于最后有效出勤的部分计 `early_minutes`（早退）；
- 中间未覆盖部分计 `absent_minutes`（缺勤）；
- 没有有效出勤时全部计缺勤，迟到和早退记零；
- 四类分钟合计恒等于应出勤分钟。

### 查询单班明细

```json
{"cmd":"shift_detail","shift":"S1"}
```

明细包含原始打卡（已排序）、休息区间、请假抵扣区间、应出勤区间、异常原因及各项分钟。

## 校验与幂等

- 拒绝未知员工、未知班次、非法时间、起止倒置（或相同）、休息超出班次、班次重叠、打卡员工与班次不一致、重复标识冲突。
- 批量导入是原子的：任一条失败则整批不落库，不留下部分记录。
- 相同记录（同标识且内容完全一致）重复导入会被忽略，不增加记录；同标识但内容不同则报冲突。

## 响应格式

成功：`{"ok":true, ...}`（导入命令附带 `imported` 计数，查询命令附带 `report` 或 `detail`）。
失败：`{"ok":false,"error":"原因"}`。

## 测试

```sh
go test ./...
```

覆盖跨夜班次、休息与请假重叠、乱序与缺卡、整班请假、班外打卡、多班汇总、批量原子性与重开一致性。
